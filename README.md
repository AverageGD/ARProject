# ARProject

🔬 **ARProject** – an interactive augmented reality (AR) mobile game for Android, where players can discover new chemical elements by combining cards. Show multiple chemical element cards in the same frame, and they will combine to create a new element!

📌 *This is a non-commercial experimental project designed to explore AR and chemistry in a fun and educational way.*

## 🎮 Game Features
- **AR Gameplay** – interact with chemical element cards in augmented reality.
- **Multiple Elements** – various chemical element cards to discover.
- **Element Creation** – combine different cards in one frame to create new elements.
- **Educational** – learn about the periodic table in an engaging way.

## 🛠️ Technologies
- Developed with **Unity** (AR Foundation)
- Written in **C#**
- Supports **Android** via ARCore

## 🚀 Installation & Running
1. Clone the repository:
   ```sh
   git clone https://github.com/AverageGD/ARProject.git
2. Install **ARCore** and **AR Foundation** packages.
3. Build and run the game on an AR-compatible Android device.
